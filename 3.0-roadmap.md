# Stride 3.0 — Roadmap (LOCKED)

## Thesis
**From "a tracker I log into" (2.0) → "a coach I check in with every morning" (3.0).**
Engagement through *personal, adaptive, kind* daily guidance — **not** social features
(single-user by design). Stays **focused**: 3 tabs, no sprawl.

## Information architecture (5 tabs → 3)
- **Today** — readiness hook + personalized "Today's call" + swipeable **day rail** (today → tomorrow → …)
  + **"Your week"** recap card on Sundays.
- **Fitness** (Weight + Train + Progress merged) — segmented **Overview / Schedule**:
  - *Overview:* trend weight + goal pace, "you're getting fitter", this-week stats, a peek at what's next.
  - *Schedule:* the FULL existing schedule, unchanged — multiple sessions/day, all Peloton detail
    (instructor/class/duration/time), C25K prescriptions, add/edit, Sync Peloton / Plan week.
- **Meals** — the simple weekly planner (unchanged).
- **You** stays the top-right account circle. **Milestone moments** pop when hit (any tab).

## The five things that make it loved (all researched, all non-social)

### Pillar 1 — Daily Readiness + an *action* (the morning hook)
- 0–100 readiness from **resting-HR trend (heaviest) + daytime HRV trend + training load**
  (Path A — daytime-only wear; progressive-enhances if sleep is ever added). Colour-coded, shows the *why*.
- **Readiness must drive a recommendation** ("so what do I do today?"). This is non-optional.

### Personalized, modality-aware recommendation ("Today's call")
- Readiness sets the **intensity dial** (push / steady / ease up).
- **Taste/programme picks the flavour, across modalities** — rides, strength, runs (NOT ride-only).
  - Rides: instructor + class type + length (e.g. "Bradley 45-min Power Zone"). Instructor/class come
    from the **Peloton iCal** feed + a one-time go-tos setup (Apple Health does NOT carry instructor).
  - Strength: learns from logged sessions (exercises, split, frequency, what's due to progress).
  - Balances modalities (e.g. "no strength in 5 days → push day today").
- **Learns over time** from synced rides + logged strength + calendar; one-time setup just seeds it.
- **Claude API** (key already held) generates the natural, varied suggestion text — a coach who knows you.
- Honest limit: no Peloton catalogue / no booking → it's a smart **nudge**; one tap opens Peloton.

### Pillar 2 — "You're getting fitter" (the plateau-buster) ⭐
- Resting HR trending **down** + VO₂ max **up** = objective proof of progress when the scale stalls.
- Uses HR/VO₂ max ingested from Health. Highest-unique-value idea for a *weight-loss* app.

### Pillar 3 — Trend & Pace + Kind Consistency
- Smoothed **trend weight** (de-noised) + goal-pace coaching ("at this pace…", no shame).
- Load-aware **kind streaks**: rest days count; anti-overtraining nudges.

### Ritual + Delight (cheap, high-love)
- **"Your week"** Sunday recap — trend Δ, sessions, calories, readiness avg, a win, a forward nudge.
- **Milestones & surprise celebration** — −5 kg, halfway, "first under 120", streak/PR records.
  Optional **share card** (image export — not in-app social).

## Decisions locked
- Readiness = **Path A** (daytime-only wear). No food logging. No social.
- Recommendation is **modality-aware** (rides + strength + runs), learns from synced data + setup, Claude-powered.

## Sequencing
- **3.1 (foundation + hooks):** Health Metrics pipe (HRV/RHR/VO₂ max) → `health_metrics` table → readiness +
  personalized "Today's call" + "getting fitter" card + the **Weight/Train/Progress merge** + day-rail + Upcoming.
- **3.2 (ritual + delight):** "Your week" recap + milestones/celebration.
